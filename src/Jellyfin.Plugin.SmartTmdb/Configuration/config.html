General

Get your token from TMDB API Settings. Required unless the JELLYFIN_SMART_TMDB_TOKEN environment variable is set.
Balanced is a good starting point. Mainstream favors popular titles. Explorer favors lesser-known titles. Custom lets you tune weights manually.
Prefer unwatched boosts unseen movies. Only unwatched hides watched movies from results. If no user is logged in, Allow is used.
Prefer next part boosts likely sequels in the same collection. Avoid same collection reduces movies from the same franchise.
Soft preference uses exponential decay based on release year distance. Strict ±10 years filters out movies more than 10 years older or newer than the source.
Prefer source language gives a small bonus to movies matching the source movie's original language. Only source language filters out everything else.
Candidates with a TMDB vote average below this value are filtered out. Default: 5.5.
Candidates with fewer TMDB votes than this are filtered out. Default: 100.

Language code for TMDB responses. Use "auto" to let TMDB choose based on request headers. Examples: en-US, de-DE. Default: auto.
How long raw TMDB responses are cached in memory, in hours. Default: 24. Maximum: 168 (7 days).
HTTP request timeout to TMDB in seconds. Default: 10. Maximum: 60.

Half-life in years for the era scoring feature. A movie released this many years from the source scores 0.5 on the era feature. Default: 15.
